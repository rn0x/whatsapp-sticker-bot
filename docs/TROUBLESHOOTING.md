# TROUBLESHOOTING

## مشاكل شائعة

### الاتصال ب WhatsApp

- **QR لا يظهر** → تحقق أنك في صفحة WhatsApp وروعيت حالة `AUTHENTICATING`. أعد فتح الصفحة أو أعد تشغيل التطبيق.
- **Pairing Code عاد كوداً ميتاً** → تأكد من الرقم (بشكل إقليمي، بلا `+` ومسافات)، وأن استدعاء `requestPairingCode` كان بعد `connection:"connecting"`. أعد المحاولة.
- **405 / HTTP Error على الاتصال** → البروتوكول تغيّر وBaileys قديم. حدّث الإصدار المثبّت، أو أعد الاتصال بعد تعديل `version` (التطبيق يحاول أخذ الأحدث تلقائياً عبر `fetchLatestBaileysVersion`).
- **الجلسة لا تتصل بعد فترة** → جلسات Multi-Device قد تتطلب تسجيل دخول الهاتف دورياً. قدّم الهاتف للشبكة وأعد محاولة.

### قاعدة البيانات

- **SQLITE_BUSY / "database is locked"** → تأكد من تشغيل نسخة واحدة فقط من التطبيق. WAL + busy_timeout يفترضان ذلك.
- **خطأ في migration** → لا تعدل `schema_migrations` يدوياً. النسخة الاحتياطية ثم إعادة تعيين.

### FFmpeg / Media

- **fatal error beim первый encode** → تحقق أن `ffmpeg-static` موجود في `node_modules` وفي `resources/ffmpeg` للاستهداف. التطبيق يبحث في PATH أيضاً.
- **فيديو لم يتأخر لكن الناتج فارغ** → مدة/دقة قصوى؛ تحقق من logs.

### الطابور

- **Jobs عالقة PROCESSING** → Sweeper يعيدها تلقائياً بعد `JOB_LEASE_TIMEOUT_MS` (10 دقائق). لا دخل يدوي إلّا بعد التأكد أن التطبيق يعمل.
- **Retry بلا تنفيذ** → تحقق `MAX_MEDIA_WORKERS > 0` وأن Disk Guard لم تُوقف الاستقبال.

### الأمان

- **نسيت PIN اللوحة** → احذف مفتاح `admin` من جدول `settings` (أعد الإعداد عند أول دخول).
- **Backup جلسة بدون كلمة مرور** → لا يمكن استعادتها لاحقاً بدونها؛ قم بعمل نسخة جديدة.

## Risks (موثّقة وواقعية)

1. **حظر الحساب/الرقم** — المكتبات غير الرسمية (Baileys) تخالف شروط WhatsApp. الاستخدام الكثيف/السريع يزيد الخطر. لحد الإدارة الشرعية استخدم WhatsApp Business Cloud API. لا توجد ضمانة بعدم الحظر.
2. **ثبات الجلسة** — قد يُطرد الجهاز بشكل عشوائي أو عند تغيير رقم الهاتف.
3. **تغير البروتوكول** — WhatsApp يغيّر البنية دورياً؛ قد يتطلب تحديث Baileys وإعادة ربط.
4. **حدود الملصقات** (الحجم/المدة/FPS) غير موثقة رسمياً — القيم الافتراضية متحفظة.

## السجلات

اللوجات في `data/logs/` وبجدول `logs`. صفحة **Logs** تسمح بحث وتصفية دون محتوى رسائل/أسرار.

## دعم

المشروع مفتوح؛ افتح issue في المستودع مع مقتطف السجل (دون أسرار).
